## Naming conventions
- **camelCase**: Used for OOP methods, classes and C++ functions.
- **PascalCase**: For project name, OOP classes and UVM generated components (except agents).
- **snake_case**: Used to name agents and Python functions/variables.
- **SCREAMING_SNAKE_CASE**: Used for every kind of constants.

The most of correct conventions usage is autogenerated by UVMEnv when you create components, objects, projects, etc. as long as you use the user interface.

Each UVM component and object (BFM, Agent, Environment, etc.) has a prefix and format each name you use with the corresponding naming convention, i.e:
```
uvmenv component create test "float alu"
# will generate
TestFloatAlu

uvmenv component create seqitem "div_transaction" TestFloatAlu
# will generate
SitDivTransaction
# into TestFloatAlu
```

Here are the assigned prefixes:
|  Prefix  |   Comp/Obj            |  Convention  |  Name example  |
|----------|-----------------------|--------------|----------------|
| Bfm      | BFM interface         | Pascal case  | BfmDefault     |
| agnt     | Agent                 | Snake case   | agnt_default   |
| Ref      | Reference model impl  | Pascal case  | RefDefault     |
| Scb      | Scoreboard            | Pascal case  | ScbDefault     |
| Sit      | Sequence item         | Pascal case  | SitDefault     |
| Seq      | Sequence              | Pascal case  | SeqDefault     |
| Test     | Test                  | Pascal case  | TestDefault    |
| Env      | Environment           | Pascal case  | EnvDefault     |
| Top      | Top                   | Pascal case  | TopAluSeq      |
